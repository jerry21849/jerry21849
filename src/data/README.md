# src/data/ — 第2輪劇本資料

## 概覽

本目錄包含戀愛綜藝模擬器的第2輪增強劇本內容。所有資料均為 JSON 格式，與 Godot 專案的 DialogueEngine 相容。

## 檔案結構

```
src/data/
├── characters.json              # 角色設定（10位核心角色）
├── story_dialogue.json          # 劇情對話（6集完整劇本）
├── endings.json                 # 結局場景（10個主要結局，含 S+ 到 D-）
├── intimate_scenes.json         # 暗示性親密場景（5個場景）
├── character_dialogue_lines.json # 角色專屬台詞庫
├── environment_descriptions.json # 環境描寫庫
└── inner_monologues.json        # 角色內心獨白
```

## 格式說明

### characters.json
每個角色包含：
- 基本資料（姓名、年齡、職業）
- 性格標籤（5個以上）
- 口頭禪與說話習慣
- 完整背景故事（500+ 字）
- 數值設定（好感度、羈絆四維）
- 內心獨白風格
- 角色成長弧線
- 人際關係圖譜

### story_dialogue.json
每集包含：
- 集數標題與副標題
- 環境設定（天氣、時間、光線、音效）
- 完整場景（含對白、動作、情緒標註）
- 角色內心獨白
- 敘事旁白

### endings.json
每個結局包含：
- 結局標題與副標題
- 完整描寫（300+ 字）
- 達成條件（好感度、羈絆、隱藏條件、情緒狀態）

### intimate_scenes.json
每個親密場景包含：
- 場景設定（地點、時間、天氣、光線、音效）
- 完整場景描寫
- 感官細節（觸覺、聽覺、嗅覺、視覺、溫度）

## 情感深度設計

### 曖昧階段（ep01-ep02）
- 眼神交會的描寫
- 不經意的肢體接觸
- 環境氛圍的烘托
- 內心的小鹿亂撞

### 心動階段（ep03）
- 深夜的星空約會
- 脆弱時刻的陪伴
- 第一次觸碰的描寫
- 心跳聲的暗示

### 確認階段（ep04）
- 雨中的告白
- 紙鶴建築模型的禮物
- 擁抱的感官描寫
- 嘴唇觸碰臉頰的瞬間

### 考驗階段（ep05）
- 誤會與衝突
- 放手的成長
- 製作人的規則變更
- 淘汰的危機感

### 暗示性親密（ep06）
- 深夜房間的曖昧
- 月光下的觸碰
- 心跳聲的交織
- 「留白」的想像空間

## 暗示尺度（15+）

所有親密場景均採用暗示性描寫：
- ✅ 用光影、心跳聲、呼吸描寫暗示
- ✅ 用溫度、氣味、觸感描寫
- ✅ 用眼神、距離、沉默營造張力
- ✅ 類似深夜綜藝的尺度
- ❌ 不寫 Explicit 描述
- ❌ 不寫成人關卡

## 與 Godot 引擎的整合

### DialogueEngine 格式
```json
{
  "id": "scene_id",
  "type": "dialogue",
  "character": "character_id",
  "text": "對白文字",
  "emotion": "情緒標註"
}
```

### GameState 數值
角色數值與 `src/engine/constants.py` 中的 `CHOICE_EFFECTS` 相容。

### EndingEvaluator 格式
結局條件與 `src/engine/scoring.py` 中的評分系統相容。
